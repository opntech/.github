# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any opntech repository, report it by email to **security@opn.tech**. Do not open a public issue for security vulnerabilities.

Include a description of the issue, steps to reproduce, and the affected repository or component. You will receive an acknowledgement within 7 days.

## Scope

This policy applies to all repositories in the opntech organization.
