# .github

Org-wide default community health files for all opntech repositories. Repositories without their own copy of these files inherit the versions here:

- `CONTRIBUTING.md` — contribution workflow and security & coding guideline
- `SECURITY.md` — vulnerability disclosure policy
- `PULL_REQUEST_TEMPLATE.md` — default pull request template
- `profile/README.md` — organization profile page

This repository must stay **public** — GitHub only applies org-wide defaults from a public `.github` repository. Do not put anything sensitive here.
